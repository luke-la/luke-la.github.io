Hexcodln't

HTML JavaScript CSS

Hexcodln't is a clone of the wordle inspired hexcode guessing game, Hexcodle.

It's designed to look and preform similarly to Hexcodle, but is made entirely on the front end so it could be served via a static site.

Hexcodln't uses a seeded psudo-random number generator to come up with colors based on the difference in date between a hardcoded start date and the current time. Guesses are saved to localstorage by the days. It's not a very complicated setup, but it seems relativly stable, excluding a notable edge case where the device itself is moved across significant time zones.

HTML Editor

C# .NET Framework

When I first re-learned HTML/JS/CSS my class was taught in Visual Studio 2022, and I was very unhappy moving from W3Schools' side by side editor to an IDE where I had to click run and launch a second program every time I wanted to view a minor change.

Obviously other, more HTML-friendly editors exist, but at the time I decided I wanted to try making my own as a pet project.

It features "Quick Buttons" which are a user-determined selection of HTML tags mapped to buttons on a toolbar. The buttons are also key-bound to the function keys for more keyboard-oriented users. Additionally, there are other editor standard features such as a tree-style view of the working directory, as well as the featured in-editor preivew which is supported via WebView 2.

Orbital Ellipse Projection

HTML JavaScript CSS Vue3

A small app that I made as a visualisation tool and to help break down some of the math I ran across while working on my Solar System Sandbox.

It's designed to generate an orthographic projection of an orbital ellipse, which basically means a flattend version, which is useful for displaying in 2d.

Solar System Sandbox

HTML JavaScript CSS Vue3

This is a work in progress.

Solar System Sandbox is a site for designing and viewing orbital patterns of solar systems.

It uses the same math as in my Orbital Ellipse Projection program but on a larger scale, more accurate units, and with multiple bodies. It also supports bodies that orbit other bodies, (satellites and subsatellites) and even binary pairs.

Future plans include simulation, presenting data that can be generated from orbital paths (such as apparent size and brightness), and a catelog of preset systems.

Sticky Notes

HTML JavaScript CSS JSON

Sticky Notes is a local-storage based visual organization tool.

Features options for text based notes, lists, and images (must be hosted elsewhere). Notes are organized into collections called boards, which are unconnected workspaces for organizing notes on different topics. Boards can be uploaded and downloaded as JSON files, for transfering between devices.

The notes themselves are drag and drop, and expand to fit the text within them.

A number of other quality-of-life features exist, such as high-contrast themes and a snapping-grid for more precise organization.
